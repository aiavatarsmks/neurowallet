# Аргон (Gemini 4 Argon) как второй разработчик

Аргон пишет код по задачам из `docs/argon-tasks/`, а Claude Code на Маке Максима проверяет каждое предложение, применяет то, что правильно, гоняет тесты и открывает PR. Сам скрипт ничего не применяет и не запускает: он только получает предложение Аргона и сохраняет его в `.argon/proposals/`.

## Настройка (один раз, на Маке)

1. Репозиторий `aiavatarsmks/neurowallet`, ветка `claude/argon-kit` (в ней лежат скрипт и задачи).
2. В корне репозитория файл `.env.local` (он в `.gitignore`, в git не попадает):

   ```
   GEMINI_PROJECT=<id проекта Google Cloud с грантом>
   GEMINI_LOCATION=global
   GEMINI_GCLOUD_CONFIG=<папка профиля gcloud, где уже выполнен вход>
   ARGON_BUDGET_USD=300
   ARGON_TASK_BUDGET_USD=30
   ```

3. Проверка: `node tools/argon/argon.mjs spent` должен показать `spent_usd: 0`.

## Как идёт одна задача

1. Ветка под задачу: `git checkout -b argon/<id> claude/argon-kit`.
2. Предложение Аргона: `node tools/argon/argon.mjs propose docs/argon-tasks/<id>.md`. Скрипт печатает путь к файлу с предложением и цену вызова.
3. Проверка предложения до применения. Отклонять всё, что:
   - трогает ключи, seed, PIN или подпись сверх того, что просит задача;
   - меняет движение денег без флага `NEXT_PUBLIC_*_ENABLED` (по умолчанию выключен);
   - тянет новые зависимости;
   - делает реальные сетевые вызовы в демо-режиме.
4. Применить правки (`replace` = точная замена куска, `write` = файл целиком), затем `cd frontend && npx tsc --noEmit && npm run lint && npx vitest run`.
5. Если тесты красные: ошибки в файл, затем `node tools/argon/argon.mjs propose docs/argon-tasks/<id>.md --feedback <файл>`. Не больше трёх кругов, мелочи проще поправить руками.
6. Коммит в `argon/<id>`, push, PR в `claude/argon-kit`. Не вливать: каждый PR смотрит Максим (или Claude в облаке по его просьбе).
7. `node tools/argon/argon.mjs spent`: сколько потрачено и сколько осталось.

## Деньги

- Каждый вызов записывается в `.argon/ledger.jsonl`. Цена считается по полной ставке после скидки ($4 за миллион входных токенов, $20 за миллион выходных, «размышления» считаются как выход), реальный счёт не выше.
- Вызов не отправляется, если вместе с худшей ценой этого вызова будет превышен общий потолок (`ARGON_BUDGET_USD`) или потолок задачи (`ARGON_TASK_BUDGET_USD`).
- Грант общий для всех проектов: этот журнал видит только расходы NeuroWallet.
